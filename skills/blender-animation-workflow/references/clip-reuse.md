# 动作素材保存与复用

动作素材由 `.blend` 库和匹配的 `.clip.json` 描述符组成。描述符固定库的绝对路径与 SHA-256、角色身份、帧率、单位和源时段。应用到新场景后生成可编辑的原生曲线。

## 准备素材

先把角色、根、相关灯材和已有原生 Action 保存到自己的独立 `.blend`。检查对象层级、独占 Action、身份标记和依赖闭包。素材协议要求的角色 Collection 及资产标记应与描述符一致。

当前应用面板读取已经准备好的库与描述符。可用 Blender 原生资产标记、保存及脚本处理自己的库；描述符字段需与实际保存数据一致。已有兼容 `blenderctl` 时，可选用其 `asset prepare` 的 `extract` 操作保存集合与必要依赖。将新库的实际资产 ID、UUID、源区间和 SHA 写入描述符。

保存源工程和素材库，分别独立打开检查。移动库后更新描述符的 `library.file`，库字节相同则保留其 SHA。`source` 用作来源记录，应用读取被冻结的库。

## 通过面板应用

1. 打开目标工程并保存工作副本。核对目标场景的 fps、fps_base 和单位。
2. 打开「动画曲线 → 动作素材复用」，选择 `.clip.json`。
3. 为双人或分件素材设置实例名称、目标起止帧、统一尺度、站位偏移和 0／90／180／270° 朝向。
4. 需要局部源区间时启用「仅复用源片段选段」，输入源起止帧。允许小数帧，必须位于库的完整源区间内。
5. 应用后检查角色数量、Action、接触、播放区间和外部依赖，保存后独立重开。

勾选「播放区间使用片段范围」会同步场景播放范围。重复应用生成独立 UUID 与 Action，Blender 自动增加的名称后缀可由身份映射解析。原生 Undo／Redo 可用于恢复场景内操作。

## 支持的描述符

| 描述符 schema | 内容与变换 |
| --- | --- |
| `animation-native-clip-v1` | 两名受支持同模板人形，身体、根和相应灯材原生动画。支持同组正均匀尺度、平移、四分之一转向、全段或选段改时。 |
| `animation-native-rigid-clip-v1` | 一个或两个无骨骼分件角色。单位静态 Empty 根，直属 MESH 部件各自拥有位置／Euler 曲线。支持统一空间变换与全段或选段。 |
| `animation-native-project-clip-v1` | 四人完整互动 Collection，四个接触、四盏灯、先后／同步关系及时间／空间锁。支持独立实例和保持接触时刻的收势改时。 |

人形或分件选段按原生曲线分割边界，保留区间内插值，舍去窗外键。选段重新保存为新库后，可用新库的实际区间和身份再应用。源窗口在原生 float32 中发生折叠或越界时会被拒绝。

分件库要求无材质静态网格和受支持的原生 TR 通道。共享 Action、NLA、驱动、额外实例、未声明子集合或不符合要求的根变换会使应用拒绝。

## 四人整段

选择四人描述符时，默认启用「四人素材沿用源时长与站位」。同一次应用带入角色、灯材、原生曲线、四次接触、事件关系和锁。

四人 schema 保持源起帧。修改结束帧时只重映射 `recovery_start` 之后的收势，接触事件位于固定前缀。绝对空间锁要求目标变换仍把锁点留在原世界位置。

四人体型差异由源素材内各角色的合法尺度和已校正曲线保留。需要改变单个角色尺寸时，先在自己的源工作副本调整根尺度及必要姿态，核对接触、支撑和世界锁，再重新保存素材。

已有多事件记录的目标场景会保留原事件，追加事件使用新实例命名空间。验证两套实例的 UUID、Action 和事件列表，再保存。

## 通过可选 CLI 应用

已安装兼容动画适配器时，先运行 `blenderctl animation clip-apply --help`。请求 envelope 为 `animation-native-clip-apply-v1`，包含 `clip` 描述符及 `instance_name`、`start`、`end`、`scale`、`translation`、`yaw_quarter_turns`，双人和分件选段另给 `source_window`。

调用时提供目标 `.blend`、目标 SHA、请求文件与实际资源清单。核对生成候选及独立重开结果。GUI 和 CLI 的核心复用操作都应通过原生接触、锁定与源数据保护检查。
