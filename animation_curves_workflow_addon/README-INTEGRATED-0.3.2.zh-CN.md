# 0.3.2：347支撑工作流与348单轴主体显示色支持集成

基于0.3.1修正版最小集成。只有“编辑所选姿态骨关键帧”支持有限不透明BODY Object.color差异；marker颜色、材质、拓扑、绑定、膝等检查不放宽。既有非目标Bezier曲线与手柄保持。允许颜色不保证视觉对比。

批量姿态、准备续写、全动作改时、支撑诊断/补偿默认仍严格颜色。自定义色对白角色能单轴续写，不代表能够直接用来做双端盖补偿。

支撑仍采用干净保存源→预检→显式生成独占工程→同进程磁盘重开；不改源、不自动导入/打开/绑定，磁盘输出不能Ctrl+Z。不是通用IK/步行。

单轴编辑克隆Action并保留原动作保护标志，保存后才持久。Undo恢复旧Action求值，可能不保留已动画骨未打键手动姿态；重要手改先另存。

此包初建时仅继承分支证据，集成实际后台/GUI/冷开结果以包外最终验收报告为准，不把两分支历史测试冒充集成通过。
