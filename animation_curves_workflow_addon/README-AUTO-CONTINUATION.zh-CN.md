# 0.2.6候选：显式准备旧FK通道续写

POSE模式只选一个标准自有无脚18骨角色及一个活动姿态骨，使用“复制动作并准备当前通道续写”，选择单轴并确认影响。仅支持现有LINEAR/CONSTANT通道；膝仅校准X轴。异常rig、共享Action、NLA、驱动、损坏限位、锁定/静音/修改器/采样通道拒绝。无AUTO/AUTO_CLAMPED时不创建副本。

操作克隆整个Action，仅所选通道的AUTO/AUTO_CLAMPED手柄侧转为FREE并保留原坐标。FREE/VECTOR/ALIGNED侧不授权改变；如果Blender重算造成任何额外差异则拒绝回滚。键点、插值、其他曲线和原Action动画内容保持。随后用原单轴编辑按钮设置/移动/删除关键帧。

原Action唯一允许的修改为开启保护标志(use_fake_user)，防止保存时丢失零用户原动作；已开启则不变。新候选不额外开启该标志。原动作先保留在当前工程内存，保存工程后才持久。本操作不自动保存或覆盖源文件，不是外部备份服务。建议另存新工程。Undo恢复绑定和原保护标志，Redo重新应用；在取消/失败时同样恢复原标志（原本True不会误清）。

LINEAR/CONSTANT当前值函数不依赖手柄，因此当下形状不变；以后改成Bezier不等同原AUTO自动调整行为。本功能不支持Bezier转换、不改变旧编辑器的严格保护策略、不提供批量原子编辑。

资格范围：Linux Blender5.2.1；后台和GUI验收分别记录在包外336报告。源码冻结前不把未完成GUI称为通过。Windows/macOS未验证。
