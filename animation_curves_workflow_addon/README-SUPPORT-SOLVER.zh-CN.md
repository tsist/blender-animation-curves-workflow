# 0.3.1 狭窄双腿固定端盖工作流（候选）
位置：3D视图侧栏“动画曲线”→“双腿固定端盖 · 独立工程”。
1. 保存干净工程，Object模式单选标准自有无脚双段腿骨架。准备已有root纯location LINEAR/FREE轨迹；骨架必须全rest原始姿态且无姿态Action。仅Linux x64/Blender5.2.1已资格运行时，scene单位1米、root静态旋转零/尺度一。
2. 点击预检，明确区间与水平平面世界Z、现有私有输出目录。1/4帧网格，固定1/32采样、最多4097点；初始双端盖必须实际在该平面。不可达整体拒绝，无候选。
3. 预检可生成后，另行确认“生成独立补偿工程”。仍重新完整预检；只创建双thigh.X/shin.X四曲线，每1/4帧LINEAR/FREE，不改root或支撑目标。严格残差门1e-6米，候选端盖/地面容差1e-5米，膝0–150°。
4. 成功结果显示独占新session中的candidate.blend，复制路径后自行打开。产品只作同worker磁盘重开验证；研发另做独立进程冷开，不混称。没有原位Action导入/Undo功能。

原工程、当前场景动作/raw姿态/播放头不修改。输出磁盘文件不能Ctrl+Z；取消不删除未知文件，保存后取消或失败可能留私有半成品，但不会发布为成功。Release仅清任务，不删除工程。
仅这类受限平盖机制，不是通用IK、步行、动态平衡或无自碰撞保证；有限采样不构成连续数学证明。已有任何姿态Action、非rest、NLA/驱动/不支持变换/曲线均拒绝，不覆盖。当前完整非目标见证对未知modifier等还可能保守拒绝。

候选实际GUI和最终独审资格见包外交付报告；不要把旧研究346通过当本包全面发布。
