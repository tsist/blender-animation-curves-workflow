# 0.2.7 候选：整个姿态 Action 改起点和时长

在3D视图侧栏“动画曲线”页签的自有角色姿态面板，POSE模式只选一个自有模板骨架，点击“整个姿态Action改起点和时长”。对话框列出当前Action全部骨/轴/键数，输入新起点、新终点并确认。所选姿态骨不限定范围，影响当前Action全部曲线。

只接受本插件标准18骨无脚模板、XYZ Euler、膝X、LINEAR/CONSTANT及两侧FREE手柄。任何非姿态曲线、空/重复通道、AUTO/Bezier、共享/NLA/驱动/修饰器/采样、损坏模板或限位、手动Action范围、循环Action、Action姿态事件标记都会整单拒绝，不跳过。最多51通道、4096键。未动画膝Y/Z非零或无X曲线膝原姿态越界亦拒绝。

全部键与手柄时间按同一正仿射映射，值、插值和形状在对应时间保持。源范围是所有键的全局最小/最大时间。目标关键帧区间限制[-1000000,1000000]；手柄可在键区间外。所有结果须精确表示为float32，不同时间映射后间距须大于1e-6。不默舍入，因此某些百分比/十进制时长会被拒绝。可先试整数倍或二分缩放，并确认全部手柄同样可表示。

复制整个Action后绑定，原Action仅增加保护标志。原动作留在当前工程内存，保存工程后才持久；操作不自动保存或覆盖源工程。Undo恢复绑定及原保护标志；原本已有保护标志不会被清除。新起止与旧区间相同则不创建副本。场景播放范围、preview范围、播放头、场景marker不改，调整预览范围需用户另行操作。

例：六曲线18键的1/13/13.5/25可整体变为1/19/19.75/37。此功能改变节奏，不新增动作姿态、物理约束或碰撞修复，不代表完整影片复刻。既有AUTO通道准备续写为单轴操作，不是本按钮隐式批量转换。

此文档写于候选后台阶段，真实GUI/Undo/Redo/冷开资格以包外最终验收说明为准。只验证Linux Blender5.2.1；不声明Windows/macOS或其他Blender版本通过。
