# 348 独立内部候选：主体显示色下单轴姿态编辑

未与347集成，不是新的正式版本。仅“编辑所选姿态骨关键帧”对话允许自有标准无脚两段腿模板的主体Object.color为有限[0,1]、alpha=1颜色。BODY按模板marker=False识别，正面标记、材料diffuse、拓扑/权重/绑定/膝和静态根门禁保持；不重置用户颜色。批次/改时/AUTO准备等其他入口仍严格拒绝自定义显示色。

对话冻结源动作/slot/身份、展示颜色、材料/节点/自定义属性/资源及视口着色环境；提交及事务中漂移整单拒绝，只回滚本次Action，不撤销其他来源的外部色彩修改。只接受简单无外部资源shader节点：Principled、Material Output、RGB、Value、MixRGB、Math、Vector Math、Emission、Diffuse、Reroute。图像纹理、脚本、Group及其他节点或ID自定义资源引用拒绝，未实现完整图像资源哈希。

编辑仍仅目标单轴：目标曲线只支持LINEAR/CONSTANT，非目标原有Bezier/AUTO_CLAMPED曲线不转换、不改键/手柄。新轴使用FREE。原Action加fake-user保护，必须保存后才持久；取消/失败恢复原保护标志，Undo恢复旧动作求值及保护标志，不承诺保留未打键手动姿态。手动仅重绑旧Action不会自动清零原来无曲线的轴；精确原场景恢复仍用保留的原工程文件。

允许显示色不等于证明任意配色、光照、机位的正面标记都可读；标记设计保持，无自动对比度或视觉质量承诺。未支持任意外部rig/移动根/透明主体/材质改色。Linux Blender5.2.1限定；公开GUI/Undo/冷开最终资格以外部报告为准。
