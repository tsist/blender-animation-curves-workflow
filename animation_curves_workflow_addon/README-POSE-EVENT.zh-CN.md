# 双角色显式同步改时（0.3.3候选）
侧栏“动画曲线 / 双角色转头事件”：填写两个标准自有rig、各自现有head.Y非端点键、同一帧差，先生成最终预览，再确认复制两个Action并一起改时。任一目标不支持整单拒绝。
仅LINEAR/CONSTANT + FREE；不改两个键的值，不转换现有AUTO/Bezier。其他所有键与handles保持；移动会改变相邻区间的时长/插值形状，锁定时点不等于区间形状不变。两键原时间差保持，不强迫双方同一时刻发生。
事件名字仅本次请求，不建立持久可编辑事件图，不锁定原生Graph Editor。没有接触/音乐/任意骨组同步。
原Action保护标志在当前工程内；只有保存后持久，不自动保存。Undo恢复两个旧Action绑定与旧动作求值，已动画骨未打键手动姿态可能丢失，建议先另存；Redo恢复本次改时。失败完整回滚是另一项保证，不等同原生Undo保留所有输入。
支持已验BODY显示色，材质/标记/拓扑仍严格。没有Windows/macOS资格，当前Linux Blender5.2.1候选待完整GUI验收。
