# 0.2.4 开发候选：当前帧双膝只读体检

在物体或姿态模式，仅选择一个本插件生成的无脚两段腿人形骨架，在“动画曲线 / 简形角色模板”点“当前帧双膝只读体检”。弹出的是本次角色、帧及子帧的快照，换帧后须重新检查。

测量来自当前 depsgraph 求值后的髋、膝、小腿末端及随大腿实际姿态旋转的 +X 铰链轴；复用 leg_contract.signed_flexion。报告物理角度与 0–150° 范围、反折/过屈、离轴及关节脱开。负 Euler 不等于反折，约束夹住的曲线过冲不等于当前实际越界。

“模板膝限位配置”另报正常、未找到/已改名、禁用/影响不足或配置改变；这不是所有约束或未来动画的保证。命名约束缺失不阻止尝试当前几何测量。非本模板、缺骨、改静置校准、镜像/非均匀世界变换、骨骼姿态缩放/剪切不支持。均匀正世界缩放允许。

不切帧、不写 Action/约束/场景属性、不修复、不保存、不生成动作；弹窗关闭即丢弃快照。未改变旧 practice/discovery 门禁，不为练习写入提供新准入。不是全片、接触、碰撞、足底或完整动作验收。

仅 Linux Blender 5.2.1 本轮限定测试；真实 GUI 尚待验收，以包外最终报告为准。未改变旧 0.2.3 包，未迁移用户工程。
