# 动画曲线插件 0.2.3 · 开发候选

本包是开发候选安装 ZIP，不是正式发行版，也没有替您安装、启用或上架。保持实际验收过的源码版本字符串，内部 VERSION 仍含 host-dev；这不代表只完成了 HOST 测试。

## 已验证的工作流

在 Blender 5.2.1 Linux 的独立测试环境中，完成新建模板、独立 FK 练习 Action、保存/冷开、实际 GUI 取消/执行/Undo/Redo/F9 参数调整，以及 Graph Editor 五条曲线可见检查。没有宣称 Windows 或其他 Blender 版本已经验收。

1. 在 3D 视图侧栏“动画曲线”创建“两段腿人形（无脚）”。两条腿仅大腿与小腿，无脚；胸前橙色方片、头前青色竖长片表示正面，正面轴为 -Y。
2. 打开“自有角色 FK 练习 · 开发候选”，点击“创建独立 FK 练习动作”。明确选择目标角色；多实例时请确认名称。
3. 设置开始/中间/结束三个递增时间，及起止/中间膝屈曲角。只接受本插件的默认姿态、无 Action 模板；已有未关键帧手工姿态、Action、NLA、drivers 或不匹配结构会被拒绝。新建未保存的模板可以使用。
4. 生成独立可编辑 Action：头转、两侧抬臂、两侧膝屈伸回位，五条曲线、每条三个 LINEAR 关键帧，不覆盖已有 Action。可 Undo/Redo。
5. 刚创建后，可立即按 F9（Adjust Last Operation）调整这次操作的参数。实际测试中 Undo/Redo 之后 F9 被 Blender 原生禁用；不要把这当作支持任意时刻重开参数面板。
6. 查看曲线时，选目标骨架，进入 Pose Mode，选相应骨骼（head、upper_arm.L/R、shin.L/R），在 Graph Editor 查看/框选全部关键帧。若启用了“仅显示所选”，没有选骨骼时曲线可能隐藏。

## 膝角与动作边界

膝参数表示物理屈曲角 0–150°，先按 rest pose 校准，再写入局部旋转。局部 Euler X 出现负数不等于物理膝反折。实际保存/冷开测试涵盖两腿共194个几何角样本，LINEAR 避免 Bezier 过冲；不保证用户后来改成其他插值、删除约束、编辑骨架后仍保持本次验收条件。

这是 FK 示例，不是 IK、接触锁定、走路系统、自动平衡或无碰撞保证。屈膝时腿端可能移动/离地。圆柱模板仍可创建，但本次新增练习动作只支持无脚人形。

原 root、其他实例、现有 Action、前标记和膝约束不由这次练习动作改写。失败会尝试回滚自身新增 Action/绑定和 pose；遇到异常外部引用会保留相关数据并明确报错，不删除他人的数据。

## 安装包与依赖

ZIP 内包含完整 addon、原有 support_resources（276个本地资源全部校验）及本次小功能/UI 更新。可以按 Blender 对旧式 addon ZIP 的正常安装方式安装到您自行选择的测试环境；本交付不自动安装。

- Blender 本体不在包内；已验版本为官方 Blender 5.2.1 Linux x86_64。
- 新模板/FK 练习 Action 在当前 Blender 内运行，不需要额外 host Python。
- 原有“参考工程左腿支撑”等旧功能仍限定冻结参考源、受测 Blender 与显式 host Python 精确哈希，并非通用角色修复工具；没有因为本次打包而放宽这些限制。
- 原只读审阅仍有独立的已保存干净源及精确运行时限制，本次没有改成可写。
- 验证了 ZIP 资源和源码完整性，不代表已在用户机器上安装测试。
