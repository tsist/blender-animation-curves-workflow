# 0.2.9 候选：已有根位置输入与多骨姿态续写

仅新增多骨“记录当前旋转姿态”对自有模板 root EMPTY 已存在 location 曲线的只读准入。根Action、slot、全部曲线元数据、原始变换与实际world求值冻结；事务不写root。仅LINEAR/CONSTANT、FREE、单slot/layer、无共享/NLA/driver/约束；旋转/缩放动画拒绝。原有静态旋转与正均匀尺度仍可用。

不新增根动画创建/编辑按钮，不开放骨平移。旧单轴/练习/准备续写/整体改时入口仍保留原门禁，不能假称全工具接续。输入不满足条件会拒绝，不清理或转换源。

根平移不等于走步。实测root平移0.4、腿保持rest，膝角合格但小腿实际mesh末端滑移约0.4场景单位，支撑负例失败。尚无IK/步频补偿、接触锁定、无滑移或无碰撞保证。仅根输入资格和姿态事务的数据保护，不是攻防成片。

本地Euler捕获，不是视觉姿态/IK烘焙。Undo回旧动作求值可能丢失已动画未打键输入；建议先保存副本，Redo恢复捕获。失败回滚是不同路径。原Action保护在保存新工程后才持久。不自动保存，不覆盖源。

仅Linux Blender5.2.1后台候选，GUI/独审状态见包外最新报告。0.2.8保留不覆盖。
