# 0.3.6 候选：首次显式 Cue 关联改时

在“动画曲线”页签使用“设置显式 Cue 拍点”，输入明确的Cue ID、BPM、FPS、起始帧、拍点，选择精确目标或显式整数帧及最大误差。预览显示事件ID/revision、三个拥有者的帧变化和精确帧/秒误差，确认后使用同一事务更新三个Action、cross记录和cue记录。不存在音频读取、识拍或自动量化。

仅支持先前范围内两模板角色head.Y与独占默认灯energy的首次关联改时。必须非零delta，不能只给已在目标时刻的事件添加标记；不支持已有cue续接、替换或删除。当前Scene空cue的旧跨域入口保持可用；已有/未知cue时旧capture/shift入口拒绝，不允许悄悄使关联失效。只读Inspect可用。不是全工程或所有Scene的锁；其他Scene共享数据、手工和其他pose编辑不受全局锁定，可能导致关联失效，Inspect将报告，不自动修复。

需重新设计时：仅在当前会话原生撤销历史仍存在时用Undo退回绑定前，或打开独立未绑定源副本；不建议手改JSON/删属性绕过门禁。不承诺保存重启后仍保留Undo历史。

非精确帧不会静默舍入。显式整数策略需要主动选择整数帧和允许误差，输入FPS必须与场景实际FPS比率一致。相邻锁键、Action身份/内容、播放头求值等原保护继续适用。Undo恢复旧动作求值，可能不保留已动画通道未打键手输值。操作不自动保存。

保留历史acw_experimental_cue属性键与explicit-cue-binding-v1数据schema，无静默迁移。Blender 5系统RNA数据与同名用户自定义IDProperty不同；任何同名用户自定义键都会阻止写入，不自动删除、覆盖或迁移。未注册RNA时拒绝检查/写入要求启用插件。正常禁用/卸载只注销定义；此版本不手工重写持久数据。

当前为待验收候选，不扩大为完整音乐同步、通用事件图、Windows验收或正式攻防片段。
