# 0.2.5候选：自有角色姿态单轴关键帧

在POSE模式仅选一个自有两段腿人形骨架及一个活动姿态骨，点击“自有角色 · 姿态单轴关键帧 / 编辑所选姿态骨关键帧”。明确选择设置、移动或删除、局部轴、源帧（可含子帧）。设置时输入角度与LINEAR/CONSTANT插值；移动时输入目标帧，不覆盖已有目标键。

膝只支持X，输入物理屈曲0–150°；其他变形骨为局部Euler-180–180°。非变形root、位移/缩放、非XYZ模式、不标准模板、损坏限位、根非均匀缩放/剪切/镜像、共享Action、drivers/NLA及目标Bezier通道拒绝。提交时重核选择，换角色/骨骼后需重开对话框。

从没有Action的模板可逐次在同一骨轴设置四个以上姿态键，新增LINEAR/CONSTANT键使用FREE手柄。旧FK练习默认AUTO键在同通道追加可能引发未点名手柄变化，系统拒绝且回滚。需要用户在Graph Editor显式选该通道键、V→Free后继续；不会自动改AUTO邻键。旧FK可直接在原未用骨/轴建新键。

每次编辑克隆Action再绑定，保护未点名键/手柄和旧Action当前会话内容；不是永久版本库，零用户旧Action可能不随保存保留。不会自动保存工程。建议在独立工作副本编辑并手动保存。标准Blender Undo/Redo与实际GUI仍待本候选验收，最终资格看包外报告。

Linux Blender5.2.1限定候选；不声明完整片段复刻、动作片段库、重定向、IK或接触/碰撞正确。0.2.4只读双膝体检与原practice/read门禁保持原样。
