# 小腿端盖支撑只读采样（0.3.0候选）

本功能测量滑移风险，不修复滑移，不创建脚/IK，不生成动作或保存工程。

仅Linux x64、已验Blender5.2.1运行时；标准自有18骨无脚双段腿模板。请先另存工作副本并保持干净，在Object模式只选一个模板骨架。动画曲线侧栏“小腿端盖支撑·只读采样”→“只读检查小腿端盖支撑区间”。明确左/右小腿、起止帧、固定世界水平面Z（米）、现有私有报告目录。

合同为静态水平平面上的平盖支撑，不是点接触/滚动/移动平台。只接收LINEAR/FREE的受支持输入，固定1/32帧采样、最多4097点。以实际世界角色高度H定工程阈值：固定端面点切向漂移0.002H、离面/穿地0.001H、累计路程0.004H、相邻采样平均速度0.01H/秒。速度不是瞬时峰值；有限采样不能证明连续时间安全。

只从已保存源复制私有SOURCE.blend，校验源SHA与角色UUID/内容后在独立worker采样。用户当前窗口不切帧、不读取未保存姿态、不写Action。取消/关闭清理复用已有只读任务owner；强杀无法保证worker finally执行，但用户现场和原文件不被采样或写入，任务不能报成功。

“SUCCEEDED”仅代表报告生成完成。若显示SAMPLED_SUPPORT_FAIL或“采样发现支撑风险”，说明已测出滑移/离地/穿地等失败，不是修复成功。报告目录内REPORT.zh-CN.md便于阅读，RESULT.json含固定12个端面顶点、重心、最低点/整shin距离、膝角、完整轨迹与阈值。原四时刻审阅仍是另一种报告，不代表已判定地面接触。

实验和GUI资格以包外最终报告为准。尚非完整步行、攻防成片、光材音乐联调或WM总验收。旧姿态捕获Undo仍恢复旧Action求值，可能丢失已动画骨未打键手动输入，建议先存副本；此只读入口本身不产生Undo动作。
