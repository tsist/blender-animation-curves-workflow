# 0.2.8 候选：所选骨骼当前旋转姿态一次写键

行为已通过有限 Linux 后台、GUI与冷开验证；本次文案澄清仍须公开对话复验，非全面发布。

在姿态模式仅选择一个自有无脚双段腿模板，选择要记录的变形骨（活动骨须在选择内）。先使用Blender姿态工具摆好姿势，再点击动画曲线面板的“为所选骨骼记录当前旋转姿态”。对话框预览角色、当前帧、全部骨名/轴/角度和新键数。

普通骨记录XYZ，包括零值；双膝只记录校准X并显示物理角。仅捕获本地Euler输入，不是视觉姿态/IK烘焙。只写当前帧LINEAR新键，不批量移动/删除、不改节奏或接触。不切换帧、不改场景范围，不自动保存。

任一目标已有当前帧或EPS近邻键、AUTO/非FREE手柄、Bezier、锁定/静音/修改器/采样，整批拒绝，不覆盖、不自动转换。旧AUTO可逐通道使用已有显式续写准备工具。共享/NLA/驱动/非标准模板/损坏膝限位/非法膝输入等拒绝。

一次克隆和绑定Action，一次Undo。原Action仅增加fake-user保护标志；保存工程后才持久，操作本身不是磁盘备份。Undo恢复绑定与原标志，原True不得变False，并按旧动作重新求值；不保留已动画骨捕获前未打键输入。建议捕获前先保存工作副本。Redo恢复本次捕获。例如捕获前手动头部25°，旧动作11.459°，Undo回到11.459°而非25°。异常失败回滚保留原始输入与此原生Undo语义不同。非选骨的未保存手动姿态不能丢失；若未选已动画通道当前输入偏离其曲线求值，本版保守拒绝。对话框打开后源、选择、时间或姿态改变，请取消后重开。

这不保证整段碰撞/接触/构图，不支持任意rig或Windows/macOS资格；当前实现与测试环境为Blender5.2.1 Linux。
